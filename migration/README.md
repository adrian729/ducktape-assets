# migration/

This directory is temporary. It holds the set plan (`plan.yaml`) for importing the old `medieval-ornaments` catalog and, later, the old-to-new lookup map. Nothing imports it: no package exports it, and the index, catalog and resolver do not know it exists. It is deleted at a dated milestone once polyhymnia and elder-scrolls have moved to the new ids.

`plan.yaml` is generated by `spikes/importer-dry-run/plan.mjs` and is meant to be hand-adjusted (triage rows, ids over 48 characters).
